# Tomcat webapp context inventory

`QuadCraft/` is the single checked-in application context. The directory name normally supplies `/QuadCraft` when deployed in an external Tomcat, subject to that container's configuration.

See [application files](QuadCraft/README.md) and [protocol/security limits](../../README.md). This tree is not itself a running server; copying it does not supply an index page, authentication, durable storage or the current browser dependency layout.
