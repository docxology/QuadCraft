# QuadrayGrid4 archived browser snapshots

Files named `quadcraft_quadgrid4_*.json` preserve historical browser state and optional descriptive suffixes. See [format boundaries](../README.md) before loading them: the type tag and actual keys, not directory name alone, determine the relevant snapshot.

These are reproducibility/debugging inputs, not current passing tests. Do not rewrite files to match current StateMap; grid4/grid5 and archived `V`/current `root` representations are not interchangeable by assumption.
