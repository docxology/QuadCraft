# Historical JavaScript experiment families

`experiments/` contains independent HTML geometry demonstrations, archived screenshots/saves and a split-script browser prototype. These are not the thirty portfolio games or the current monolithic [browser application](../browser/README.md).

Use [the experiment index](experiments/README.md) to choose a snapshot. There is no automatic promotion/synchronization pipeline between versions, no universal save schema and no evidence-based ranking of one experiment as production-ready.
