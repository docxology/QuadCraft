# Manuscript Status: Available Artifacts and Publication Boundaries

## Repo type

QuadCraft contains experimental game/engine code and engineering/mathematical documentation. This status concerns manuscript artifacts in `docs/manuscript/`; it is not a claim that interactive software cannot support research.

## Evidence checked

The directory inventory at this documentation audit contains `README.md`, `AGENTS.md`, and this status page. It contains no manuscript body, generated sections, figures, or finished publication artifact. The directory itself exists; it must not be described as absent.

The [historical technical discussions](../other/README.md) are maintained explanatory documents, not a generated finished manuscript. [Native coordinates](../../src/core/coordinate/Quadray.h), [world storage](../../src/core/world/World.h), and [meshing](../../src/render/mesh/ChunkMesher.cpp) support source-level implementation descriptions, not empirical performance or publication claims.

## Why no publication-target manuscript applies today

No completed publication-target manuscript is supplied in this directory. The status does not establish a publication venue, completed experiments, validated tessellation, or generated figure pipeline. Mathematical derivations and source inspection must not be represented as measurements from an exercised engine.

For the maintained mathematical starting point, consult the [canonical coordinate contract](../quadray_coordinates.md), [quadray mathematics](../mathematics/quadray_coordinates.md), [tetrahedral geometry](../mathematics/tetrahedral_geometry.md), and [IVM units](../mathematics/ivm_synergetics.md). Physical quadrays are rank-three common-offset classes; four coefficients do not establish four independent spatial dimensions or a fixed-sum physical constraint.

## What would trigger creating one

A concrete research contribution with reproducible methods, source/version provenance, actual results, and corresponding manuscript artifacts would justify changing this status. Software methods papers, educational studies, and measured algorithm comparisons are possible forms, not completed work asserted here.
