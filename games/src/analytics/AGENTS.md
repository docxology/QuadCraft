# Maintaining source-scan metrics and reports

Read [analytics reference](../../doc/analytics_reporting.md) and `__init__.py`. Preserve the distinction between filesystem discovery, text matching and actual program behavior. A module filename/class name in text is not resolved imports, inheritance or executed use.

Document scoring weights/thresholds as formatting heuristics, never measured quality or correctness. Count shared CSS as the implementation does; JSON intentionally contains fewer fields than GameMetrics. Use explicit scan roots, retain diagnostic issues and generate fresh dated reports rather than copying timeless file/line/test totals.
