# Starter-game file generator

`__init__.py` defines `GameScaffold(game_key, display_name, *, grid_size=8, tick_rate=16, optional_modules=None)`, `create(*, overwrite=False)` and `validate()`. Tick rate is milliseconds per update; generated callbacks forward fixed seconds.

Read [scaffold guide](../../doc/scaffold_guide.md) before creating files. The default path nests games/games, generated projection uses an incompatible call signature, and local run.sh serves too narrow a root. Output is not implemented gameplay; basic file/default checks cannot establish browser correctness.
